# Güvenlik / Security

BlessedLine’ın Windows tarafında güncel güvenlik düzeltmeleri son yayımlanan sürümde bulunur. Linux desteği önizlemedir.

Bir açık bulursanız GitHub’ın **Security → Report a vulnerability** bölümünü kullanın. Form görünmüyorsa GitHub üzerinden depo yöneticisinin özel bildirim özelliğini etkinleştirmesini isteyin. Herkese açık issue ve ekran görüntülerinden kullanıcı adı, dosya yolu, IP, SSID, erişim anahtarı ve kişisel verileri çıkarın.

Report a security issue through **Security → Report a vulnerability**. Remove usernames, paths, IP addresses, SSIDs, access keys and other personal data from public issues and screenshots.
